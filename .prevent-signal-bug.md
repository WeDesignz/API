# ⚠️ CRITICAL: Product.save() Signal Bug Prevention

## Quick Reference

**NEVER DO THIS:**
```python
product.status = 'active'
product.save()  # ❌ WILL CAUSE TIMEOUTS
```

**ALWAYS DO THIS:**
```python
Product.objects.filter(pk=product.pk).update(status='active')  # ✅ CORRECT
```

## Why?

The `Product` model has a `pre_save` signal that generates design numbers. This signal queries the Studio model and can hang, causing 10+ second timeouts.

## Before Committing

1. Search your code for: `product.save()` or `Product.objects.*.save()`
2. If found, replace with `.update()` method
3. Verify the change doesn't break functionality

## Files to Check

- `API/CoreAdmin/models.py` - DesignApproval methods
- `API/CoreAdmin/views.py` - design_action endpoint
- Any new code that updates Product status/metadata
